# Quiz Battle

A real-time multiplayer quiz app built with **Flutter**, **Firebase**, and **Gemini AI**.
Players join battle rooms, answer AI-generated questions at the same time, and compete for the top spot on the leaderboard.

Mini Project 3 - Edges For Training.

---

## Features

- **Authentication:** email/password and Google Sign-In, with persistent sessions, input validation, and friendly error messages.
- **Profile setup:** display name, 2-3 favorite topics, and preferred difficulty on first login.
- **Home dashboard:** greeting, quick stats (battles, wins, streak), Daily Challenge card, Solo Practice / New Battle / Join Battle buttons, and a live list of public rooms.
- **Battle lobby:** create public or private rooms (6-digit code), live player list, real-time chat, ready checkboxes, and a host-only Start Battle button.
- **Battle arena:** animated timer, four answer buttons, answered/thinking indicators, live scoreboard, correct/wrong reveal with an AI explanation, and auto-advance after 3 seconds. All devices stay in sync.
- **Battle complete:** winner announcement with confetti, final ranking, accuracy and points, Play Again (new room with the same settings), and automatic stats update.
- **Solo Practice:** play against an AI bot whose speed and accuracy depend on the difficulty.
- **Daily Challenge:** one shared quiz per day with +100 bonus points (once per day).
- **Leaderboard:** Global top 50 (your row highlighted) and a Friends tab.
- **Profile:** editable name, level badge, stats, favorite topics, difficulty, change password / email, and sign out.

## AI features (Gemini via Firebase AI Logic)

1. **Quiz generation:** Gemini returns structured JSON (question, 4 options, correct index, explanation) using a response schema.
2. **Answer explanations:** each question carries a short AI explanation shown after the reveal.
3. **Function calling - Educational Resource Finder:** the model asks to call `findStudyResources(topic)`, the app runs the function (a mock that builds video, article, and course links), sends the result back to Gemini, and shows the final answer. It is available from the results screen through the **Find study resources** button.

## Firestore data model

| Collection | Contents |
|---|---|
| `users/{uid}` | Profile, topics, difficulty, stats (totalBattles, wins, streak, totalPoints), friends list |
| `battleRooms/{roomId}` | Settings, status (waiting / active / finished), players, AI questions, currentQuestionIndex, phase |
| `battleRooms/{roomId}/answers/{uid_questionIndex}` | Each player's answer, time taken, and points |
| `battleRooms/{roomId}/messages/{id}` | Lobby chat |
| `battleRooms/{roomId}/results/{uid}` | Marker that a player's stats were already counted |
| `dailyChallenges/{yyyy-MM-dd}` | The shared Daily Challenge quiz for that day |

The Global leaderboard reads `totalPoints` from `users`, so it updates live without a separate collection.

### How the real-time sync works

All devices listen to one room document. Its `currentQuestionIndex` and `phase` (`question` or `reveal`) drive the game. When everyone has answered, or the timer ends, a device asks Firestore to change the phase through a guarded transaction. The first request wins and the others do nothing, so a question is never skipped twice.

## Setup

### Prerequisites

- Flutter SDK and an Android emulator (with Google Play) or a physical device
- Node.js, the Firebase CLI (`npm install -g firebase-tools`), and the FlutterFire CLI (`dart pub global activate flutterfire_cli`)
- A Google account for Firebase

### 1. Get the code

```bash
git clone <your-repository-url>
cd quiz_battle
flutter pub get
```

### 2. Create the Firebase project

1. Open the [Firebase console](https://console.firebase.google.com) and click **Add project**.
2. **Build > Authentication > Sign-in method:** enable **Email/Password** and **Google**.
3. **Build > Firestore Database:** create the database.
4. Set the Firestore rules (Firestore > Rules):

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```

### 3. Connect the app to Firebase

```bash
firebase login
flutterfire configure
```

Select your project and the Android platform. This generates `lib/firebase_options.dart`.

### 4. Google Sign-In (Android)

Get your debug SHA-1 and SHA-256 fingerprints:

```bash
keytool -list -v -alias androiddebugkey -keystore ~/.android/debug.keystore -storepass android -keypass android
```

(On Windows use `"$env:USERPROFILE\.android\debug.keystore"` as the keystore path.)

In the Firebase console go to **Project settings > your Android app > Add fingerprint** and paste both values. Then run `flutterfire configure` again.

### 5. Configure the AI API (Gemini)

1. Firebase console > **Build > AI Logic > Get started**.
2. Choose the **Gemini Developer API** (free to start). Firebase manages the key, so **no API key goes in the app code**.
3. The model name is one constant in `lib/services/ai_service.dart`:

   ```dart
   const String kGeminiModel = 'gemini-3.1-flash-lite';
   ```

   If Firebase reports "model not found", change this value to a currently available Gemini model. This one constant controls quiz generation and the function calling tool.
4. In **App Check > APIs**, make sure **Firebase AI Logic** is set to **Unenforced** (App Check is not used in this project).

### 6. Run

```bash
flutter run
```

## How to play

1. Sign up (or use Google), then complete the profile setup.
2. Tap **New Battle** to create a room, or **Join** a public room from Home. For a private room, use **Join Battle** and enter the 6-digit code.
3. Everyone ticks **I'm ready**, and the host taps **Start Battle** (at least 2 ready players).
4. Answer before the timer ends. Correct answers earn 500 points plus up to 500 for speed.
5. See the results, then press **Play Again** or **Home**.

To test multiplayer on one computer, run two emulators (or an emulator and a phone) with two different accounts.

## Troubleshooting

| Problem | Fix |
|---|---|
| `firebase_app_check ... Too many attempts` | Unenforce App Check for Firebase AI Logic, make sure the app does not use `firebase_app_check`, then run `flutter clean` and restart |
| "model not found" | Change `kGeminiModel` in `ai_service.dart` |
| `429` / quota errors | The free tier has per-minute limits. Wait a minute and retry |
| Google Sign-In `ApiException: 10` | Add your SHA-1 and SHA-256 fingerprints, then re-run `flutterfire configure` |
| `permission-denied` | Check the Firestore rules above |

## Known limitations

- Friends are one-way (you add a friend by email); a full friend system is out of scope.
- The profile picture is the Google photo or the initial of the display name (no custom upload).
- A player who force-closes the app during a lobby or battle stays in the room until it is cleaned up manually.
- Solo Practice does not change battles, wins, or streak; only the Daily Challenge bonus adds points.
